# Archive

Nothing in this directory is maintained. Every file here closed, shipped, or was
superseded before it was moved — the one-line header at the top of each file says
what it recorded and when.

Do not cite anything in here as authority for current behaviour. Pointing at a path in
here as a historical record of what was done — the way `docs/strategy/roadmap.md`'s
History table and `docs/strategy/decisions.md`'s Source column do — is fine; that is a
historical citation only, not a live link, and it is not evidence for how the system
behaves today. Cross-references between archived files (and from an archived file back
out to a path that has since moved) are left exactly as they were on the day the work
closed; a dead link inside this directory is correct, not a bug, and is not repaired
when its target moves.

If something in here is still true today, it does not belong in the archive:

- a standing fact or decision belongs in `docs/strategy/`
- outstanding work belongs in a GitHub issue

See `docs/decisions/0002-documentation-architecture.md` for the policy this archive
follows ("is it finished? mark it closed in its first line; archive when
unreferenced").
